Composition Macros Layer 7
See how the macros expand and iterate. for_each_connected_output_where filters outputs with a predicate. for_each_output_combo drives the backtracking DFS to yield all valid N-output combinations.

for_each_connected_output_where

#define for_each_connected_output_where(display, output, pred) \
    for_each_connected_output(display, output) \
        for_each_if(pred)
⬇ expands to ⬇
for (output = &display->outputs[0]; output < ...; output++) if (igt_output_is_connected(output)) if (pred)
Example: pred = igt_output_supports_dsc(fd, output) && igt_output_supports_hdr(fd, output)

for_each_output_combo

#define for_each_output_combo(display, outputs, n, preds) \
    for (int __ok__ = _first_output_combo(display, outputs, n, preds); \
         __ok__; \
         __ok__ = _next_output_combo(display, outputs, n, preds))
⬇ execution flow ⬇
1. _first_output_combo() → calls _find_next_combo(slot=0) → DFS finds first valid combo
2. Execute loop body with outs[0], outs[1] assigned
3. _next_output_combo() → clears last slot → DFS resumes → finds next combo
4. Repeat until _find_next_combo() returns 0 (exhausted)
